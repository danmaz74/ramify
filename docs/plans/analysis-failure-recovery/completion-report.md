## Workflow and public result

The installed command answered ownership without starting a daemon, then completed A→B→C→D against one private project and one resident daemon. A published both API and architect views. Removing two provider exports in B produced two distinct missing-export findings with producer IDs, declaration paths and link-stage references. Ownership still answered. Affected refused the invalid current analysis, and materialization left both generated view trees byte-identical to A. A second invalid edit in C retained A as the completed baseline and both B/C observed paths. A resident request was cancelled at the actual check frame; the client sent `cancel`, exited 130 without a document, and did not reset the daemon. A separate batch check was cancelled at acquisition. After a reportless malformed-declaration measurement failure, D repaired and extended the provider. Its completed check omitted recovery, reused the same daemon PID and published changed bytes in both view trees. The owned daemon stopped in `finally`, and no owned child survived. [Process witness](../../../src/tests/ownership-process.test.ts) and [final-build broad test log](evidence/iteration7-npm-test-final-build.log.gz) establish this built boundary; the earlier [CLI composition receipt](iterations/iteration6-results.md) covers further current-envelope variants. The earlier [focused log](evidence/iteration7-focused.log.gz) predates the resident-cancel addition and is not cited for it.

The new client presented with an old `/2` daemon record exited 2 with an explicit `incompatible` diagnostic. An old `/2` client presented with a new `/3` record exited 2 with a generic malformed-record/unavailable diagnostic because its old discovery parser cannot decode future metadata. Normal discovery separates builds by build key; these observations injected a foreign record at the client's key. Controlled private metadata and a Unix socket relay then carried each installed client to the opposite real daemon handshake. Both clients sent only `hello`, received explicit incompatibility, exited 2, and sent no operation request. The relay is an explicit test control, not normal discovery. [Installed peer receipt](evidence/iteration7-installed-peers.json) and the [iteration 5 built-module socket receipt](iterations/iteration5-results.md) delimit the two claims.
