## Evidence

Give one cited fact per bullet. Preserve scopes, counts, coverage, and unknown
states from the evidence.

## Answer

State the conclusion first. Separate interpretation and recommendation from
the factual evidence above.

## Alternatives

Required for placement and refactoring. Include preserving the existing
structure and name the strongest rejected alternative with the reason it lost.

## Proposed changes

When applicable, give exact `module.ramify` declaration lines, ownership moves,
or a new-module brief containing parent, purpose, and tags. Do not claim these
changes were applied.

## Not verified

State semantic uncertainty, unavailable details, incomplete dependency or test
evidence, coverage limits, and checks not run. A negative discovery result must
say that it is not proof of absence.

## Next step

Name the bounded action an engineering agent or plan should take next.
