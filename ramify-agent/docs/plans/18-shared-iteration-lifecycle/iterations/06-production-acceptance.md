## Verification and exit criteria

All SI01–SI18 and AE01–AE18, with SI15/AE18 live. They may share the same delivery
run only when it establishes every required observation. Scripted tests cannot
close live or real-provider cases. Zero selected scenarios cannot certify them.

Run the required audits against exact provider/consumer revisions and all
declared configurations, including an applicable full final project audit.
Preserve failures and identify missing evidence; do not retry an unchanged
failure without a specific hypothesis.

Exit: current source passes required checks, real provider conformance and
live delivery/repair; deleted mechanisms are absent from production.
A failed or incomplete witness leaves acceptance open.
