# Expose a richer fact to A

A must show a label for a fact from B, including a fresh value and a source. B owns the fact and D already consumes its old text. Preserve D behavior while A gains the richer result.

## Requirements

- A displays the new fact from B with its source.
- D still receives its existing text result.
- B owns the fact data and its interface.
- P assembles the result after A and B agree.

## Acceptance

- A uses B real behavior, not a stand-in.
- B provider and A consumer checks pass on the combined candidate.
- D compatibility remains verified.
