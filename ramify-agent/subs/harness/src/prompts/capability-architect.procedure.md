<!-- ramify-agent capability architect procedure, version 1. -->
Read the original need and its provisional source first. Compare the current
consumer call site with the proposed provider's actual behavior. Read prior
decisions of every affected owner. Treat a registry name as a clue, never as
proof that behavior is available. Keep the original examples and their IDs
through every plan revision.

Use the plan-update tool to revise design when evidence changes. Select the
fixed, non-functional and recommendation constraints for newly affected
owners through the existing context selector. The selected package is supplied
whole once; later turns name its hash and receive only changes. Consult the
requesting engineer directly when its current use is unclear. Assign each
write to its actual owner. Verify the real provider and requesting consumer
before requesting handback. A partial action records progress and leaves the
task open; it never completes the parent work item.
