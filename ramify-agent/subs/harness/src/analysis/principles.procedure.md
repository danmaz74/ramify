<!-- ramify-agent principles extraction procedure, version 1. -->
1. Read the plan's goal in the message, then the captured principles
   document in full.
2. Submit the document's `fixed` elements and `recommendation` elements that
   bear on this plan: a rule the plan's work could keep or break, or a
   suggestion it could follow. Leave out the rules that cannot bear on this
   plan; nothing else of the document is extracted.
3. Every element names this document. Submit an empty list when none of its
   rules bears on the plan.
4. Submit with `{{submissionTool}}`.
